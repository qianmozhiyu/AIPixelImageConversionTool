# AIPixelImageConversionTool · AI 像素图转换工具

> 该工具将 AI 扩散模型生成的伪像素图一键转换为规范像素图。
> 
> One‑click conversion of fake pixel art from AI diffusion models into clean standard pixel art.

## 中文说明
### 简介
> 将AI生成的伪像素图转化为像素图。
> 
> 支持导入文件夹批量处理
> 
> 提供简易的编辑功能，用于手动修复没能完美处理的像素图
>
> 编辑器能力与快捷键：画笔(B)/橡皮(E)/吸管(I)/油漆桶(G)/直线(L)/矩形(U)/圆形(C)/框选(M)；
> 圆形笔刷、网格开关；Shift+S 循环对称（可左右/上下/四象限镜像）、X 交换前/背景色、
> 右键取背景色、Alt+左键临时吸管、Shift 临时直线/正圆；框选后可拖动移动（携内容），
> 或剪切(Ctrl+X)/复制(Ctrl+C)/粘贴(Ctrl+V)/水平翻转(H)/垂直翻转(V)；
> 画笔光标实心跟随鼠标（圈内圈外均为笔刷色）；滚轮以鼠标为中心缩放、Ctrl+0 重置视图、
> 双击适配视图、Ctrl+Z 撤销、Ctrl+Y 重做

> 
>Provide simple editing functions to manually fix imperfect conversion results.

`Input Image → Denoise → (Optional Resize: Upscale) → Grid Detection → Block Extraction → Palette Refinement → Standard Pixel Art`
